# LeetCrafting Features

LeetCrafting registers a single **crafting** feature: custom food and condiment items plus the recipes that make them. It is server-wide — open to all when enabled, with no permission node.

| Feature | ID | Config file | Document |
|---|---|---|---|
| Crafting | `crafting` | `crafting.yml` | [crafting.md](crafting.md) |

LeetCrafting also owns the item-texture resource pack served to clients. See [Resource Pack Distribution](../../resource-pack.md).
