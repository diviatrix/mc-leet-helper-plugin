# LeetSkills Features

LeetSkills registers the **skills** feature: an XP-spent skill tree opened with `/skills`. It spans two config files — the skill definitions and the tree topology — and persists player levels in its own SQLite store.

| Feature | ID | Config files | Document |
|---|---|---|---|
| Skills | `skills` | `skills.yml` + `skill-tree.yml` | [skills.md](skills.md) |
